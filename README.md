# 📖 QURAN MEMORISATION — متابعة حفظ القرآن الكريم

بسم الله الرحمن الرحيم

تطبيق ويب بسيط (يعمل على الهاتف والحاسوب، وحتى بدون إنترنت) لمتابعة حفظ القرآن الكريم وتثبيته على المدى البعيد باستخدام تقنيتين من علم الذاكرة:

- **الاسترجاع النشط (Active Recall):** عند المراجعة لا يُعرض عليك النص، بل رقم الصفحة وبدايتها فقط، فتسمّع من ذاكرتك ثم تتحقق.
- **التكرار المتباعد (Spaced Repetition):** بعد كل تسميع تقيّم نفسك (نسيت / صعب / جيد / سهل)، فيحدد التطبيق موعد المراجعة القادمة. الصفحات الضعيفة تتكرر كثيراً، والراسخة تتباعد (غداً ← 3 أيام ← أسبوع ← أسابيع ← أشهر).

## المميزات

| الميزة | الوصف |
|---|---|
| ➕ تسجيل صفحة محفوظة | رقم الصفحة (1–604)، السورة تُملأ تلقائياً |
| 🌐 جلب نص الصفحة | بضغطة زر من [alquran.cloud](https://alquran.cloud) بالرسم العثماني |
| 🔗 كلمات الربط | الكلمات التي تربط بها الآيات، تظهر كتلميحات تدريجية عند التعثر |
| 🧠 الصورة الذهنية | القصة أو التخيل الذي ساعدك على الحفظ |
| 🖼️ صور مساعدة | ترفع صوراً (تُصغَّر تلقائياً وتُحفظ على جهازك) |
| 🧩 اختبار الفراغات | يُخفي كلمات من الصفحة وتضغط عليها لكشفها |
| 🔗 ربط الصفحات | بعد كشف الإجابة يذكّرك ببداية الصفحة التالية |
| 🗺️ خريطة المصحف | 604 خانة ملوّنة حسب قوة حفظ كل صفحة |
| 🔥 الإحصائيات | الصفحات المستحقة، نسبة الحفظ، الأيام المتتالية |
| 💾 نسخ احتياطي | تصدير/استيراد ملف JSON لنقل بياناتك بين الأجهزة |

## طريقة الاستعمال

1. حفظت صفحة؟ اضغط **«＋ حفظت صفحة جديدة»** وأدخل رقمها، واجلب النص، واكتب كلمات الربط والصورة الذهنية.
2. كل يوم افتح التطبيق واضغط **«ابدأ المراجعة»**.
3. لكل صفحة: سمّعها بصوت مسموع ← اكشف الإجابة ← قيّم نفسك بصدق.
4. إذا اخترت «نسيت» تعود الصفحة في آخر الجلسة، وتُراجَع غداً مجدداً.

## تشغيل التطبيق على الهاتف (GitHub Pages)

التطبيق ملفات ثابتة (HTML/CSS/JS) بدون خادم:

1. في المستودع: **Settings ← Pages**.
2. في **Source** اختر **Deploy from a branch**، ثم الفرع واختر المجلد `/ (root)` واحفظ.
3. بعد دقيقة يصبح متاحاً على الرابط: `https://<اسم-المستخدم>.github.io/Quran-memrisation/`
4. افتحه من الهاتف ← قائمة المتصفح ← **«إضافة إلى الشاشة الرئيسية»** ليصبح كتطبيق.

> ملاحظة: GitHub Pages للمستودعات **الخاصة** يحتاج اشتراك GitHub Pro. إن كان حسابك مجانياً، اجعل المستودع عاماً (البيانات الشخصية لا تُرفع أبداً، فهي محفوظة على جهازك فقط).

## الخصوصية والبيانات

كل بياناتك (الصفحات، الملاحظات، الصور، تقدم المراجعة) محفوظة **في متصفحك على جهازك فقط** (IndexedDB). لا يوجد خادم ولا حساب. لذلك **صدّر نسخة احتياطية بانتظام** من صفحة الإعدادات.

## بنية المشروع

```
index.html            الواجهة
css/style.css         التصميم (يدعم الوضع الليلي)
js/surahs.js          السور وصفحات بدايتها في مصحف المدينة
js/db.js              التخزين (IndexedDB + localStorage)
js/srs.js             خوارزمية التكرار المتباعد (SM-2 معدّلة)
js/app.js             منطق التطبيق
sw.js                 العمل بدون إنترنت
manifest.webmanifest  التثبيت كتطبيق على الهاتف
```

## خوارزمية المراجعة

| التقييم | الأثر |
|---|---|
| نسيت | تعود لبداية الجدول (غداً) وتعاد في نفس الجلسة |
| صعب | فاصل أطول قليلاً (×1.2) ويقل معامل السهولة |
| جيد | الفاصل × معامل السهولة (يبدأ بـ 2.5) |
| سهل | فاصل أطول ويزيد معامل السهولة |

الحد الأقصى بين مراجعتين 180 يوماً افتراضياً (قابل للتعديل من الإعدادات)، حتى لا تغيب أي صفحة طويلاً.
