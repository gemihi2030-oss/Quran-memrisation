# 📖 QURAN MEMORISATION — متابعة حفظ القرآن الكريم

بسم الله الرحمن الرحيم

تطبيق ويب (يعمل على الهاتف والحاسوب، وحتى دون إنترنت) لتثبيت حفظ القرآن الكريم على المدى البعيد بتقنيتين من علم الذاكرة:

- **الاسترجاع النشط (Active Recall):** عند المراجعة لا يُعرض عليك النص، بل رقم الصفحة وبدايتها فقط. تسمّع من ذاكرتك، وتستعين بـ**مفاتيحك** (كلمات الربط والصور الذهنية والصور التي حفظت بها) عند التعثر فقط.
- **التكرار المتباعد (Spaced Repetition):** بعد كل تسميع تقيّم نفسك (نسيت / صعب / جيد / سهل)، فيحدد التطبيق موعد المراجعة القادمة: غداً ← 3 أيام ← أسبوع ← أسابيع ← أشهر. الضعيف يتكرر أكثر، والراسخ يتباعد.

## التشغيل

يحتاج [Node.js](https://nodejs.org) فقط (بلا أي مكتبات):

```bash
cd quran-memorisation
npm start
```

ثم افتح <http://localhost:8080>

- `npm run start:lan` لفتحه من هاتف متصل بنفس شبكة الـ Wi-Fi (للتجربة).
- `npm test` لتشغيل الاختبارات.

## المميزات

| الميزة | الوصف |
|---|---|
| ➕ تسجيل صفحة | تكتب رقم الصفحة (1–604) فتُجلب آياتها تلقائياً بالرسم العثماني، مع السورة والجزء والحزب |
| 🔑 مفاتيح لكل آية | **كلمة ربط** + **صورة ذهنية/ملاحظة** + **صورة** لأي آية |
| 🔑 مفاتيح للصفحة | بداية الصفحة، كلمات الربط (تسلسل المواضيع)، القصة/المتشابهات، صور |
| 🎙️ تسميع الصفحة | تلميحات تدريجية: نهاية الصفحة السابقة ← كلمة ربط ← صوري ← الصورة الذهنية |
| 🎯 آية بآية | يظهر مفتاح كل آية فتسمّعها، تكشفها، وتحكم: أصبت أم أخطأت |
| 🧩 الفراغات | الصفحة مع كلمات مخفية تكشفها بالضغط |
| 🔴 تسجيل الأخطاء | تضغط على الآية التي تعثرت فيها؛ يقترح التطبيق التقييم ويتذكر نقاط ضعفك |
| 🔗 ربط الصفحات | بعد الكشف يذكّرك ببداية الصفحة التالية |
| 📚 تسجيل دفعة واحدة | للحفظ القديم (مثلاً جزء عمّ)، مع توزيع المراجعات على عدة أيام |
| 🗺️ خريطة المصحف | 604 خانة ملوّنة حسب قوة الحفظ، مقسمة على الأجزاء |
| 📊 الإحصائيات | المستحقات، المراجعات القادمة (7 أيام)، الأيام المتتالية، نسبة التذكر، الصفحات الضعيفة |
| 📶 دون إنترنت | تنزيل المصحف كاملاً مرة واحدة + تثبيت التطبيق على الشاشة الرئيسية |
| 💾 نسخ احتياطي | تصدير/استيراد JSON (يقبل ملفات النسخة الأولى أيضاً) |
| 🌙 الوضع الداكن | تلقائي أو يدوي، مع حجم خط الآيات قابل للتعديل |

اختصارات الحاسوب أثناء المراجعة: **مسافة** = إظهار، **1 – 4** = التقييم.

## استعماله على الهاتف

التطبيق ملفات ثابتة، فيمكن نشره مجاناً على **GitHub Pages** أو **Netlify** (يلزم رابط https ليعمل التثبيت ودون إنترنت):

1. ارفع محتوى هذا المجلد إلى مستودع GitHub.
2. **Settings ← Pages ← Deploy from a branch** ← اختر الفرع والمجلد `/ (root)`.
3. افتح الرابط من الهاتف ← قائمة المتصفح ← **«إضافة إلى الشاشة الرئيسية»**.

> إن كنت تستعمل النسخة الأولى على نفس الرابط، تُرقّى بياناتك تلقائياً. وإن كانت على رابط آخر: صدّرها من النسخة الأولى واستوردها هنا.

## الخصوصية والبيانات

كل بياناتك محفوظة **في متصفحك على جهازك فقط** (IndexedDB). لا خادم ولا حساب. لذلك **صدّر نسخة احتياطية بانتظام** (يذكّرك التطبيق كل أسبوعين). الاتصال الخارجي الوحيد هو جلب نص الآيات من [alquran.cloud](https://alquran.cloud).

## خوارزمية المراجعة (SM-2 معدّلة)

| التقييم | الأثر |
|---|---|
| نسيت | تعود الصفحة غداً، وتُعاد في آخر الجلسة نفسها، ويقل معامل السهولة |
| صعب | فاصل أطول قليلاً (×1.2) ويقل معامل السهولة |
| جيد | الفاصل × معامل السهولة (يبدأ بـ 250٪) |
| سهل | فاصل أطول ويزيد معامل السهولة |

- المراجعة المتأخرة التي تتذكرها رغم التأخير تُحتسب لصالحك.
- تذبذب ±5٪ حتى لا تتكدس الصفحات المحفوظة في نفس اليوم على نفس الموعد.
- أقصى فاصل 120 يوماً افتراضياً (قابل للتعديل) حتى لا تغيب أي صفحة طويلاً.
- التقييم المقترح: لا أخطاء ← جيد · أخطاء قليلة ← صعب · أكثر من 30٪ من الآيات ← نسيت.
